# Do 6 aos 22 — ordem de publicação

O Instagram mostra o post **mais recente no canto superior esquerdo**. Para a grelha ficar

| | | |
|---|---|---|
| Introdução | Lobitos | Exploradores |
| Pioneiros | Caminheiros | Vem conhecer-nos |

publica por esta ordem, com poucos minutos de intervalo, **e sem nada entre elas**:

1. `5_convite` (Vem conhecer-nos)
2. `4_caminheiros`
3. `3_pioneiros`
4. `2_exploradores`
5. `1_lobitos`
6. `0_intro` (última, fica no canto superior esquerdo)

Com 2 posts fixados, as 6 caem em 1+3+2 células: o desenho continua coerente (faixa de cor + foto a alturas constantes),
mas a leitura em 2 linhas completas só existe sem fixados. Qualquer post novo empurra tudo uma célula.

Formato: 1080×1440 (3:4). Se a app recusar 3:4 no carrossel, usar 4:5 corta ~2,5% de cada lado.
Legendas em `output/seccoes/<parte>/legenda.txt`.
